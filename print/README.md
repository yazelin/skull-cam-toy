# 心跳凸輪 · 3D 列印版

兩種印法,選一種:

## A. 列印原生版(hp-*.stl,推薦)

跟木板版同一套機構重新設計:**9 種零件、共印 10 件、全程免膠**。
[3D 模擬與逐項檢查](../heart-print.html)、組裝五步都在獨立頁面。

- 箱身(底板+四牆)一體印、頂蓋含導套與壓入唇一體印
- 凸輪/曲柄用 **D 型軸孔**傳扭力,免膠
- 軸環換成**間隔套**:凸輪置中靠套管頂住,裝歪不可能
- 「包紙墊隙」那步不用了:間隙直接印在幾何裡

| 檔案 | 零件 | 件數 | 列印方向 |
|---|---|---|---|
| hp-01-body.stl | 箱身 | 1 | 開口朝上,照檔印 |
| hp-02-cap.stl | 頂蓋 | 1 | 檔已翻好(導套朝上),裝配時翻回 |
| hp-03-cam.stl | 偏心凸輪(D 孔) | 1 | 平躺 |
| hp-04-spacer.stl | 間隔套 | 2 | 站著 |
| hp-05-follower.stl | 推桿 | 1 | 平躺 |
| hp-06-heart.stl | 心 | 1 | 平躺(換紅色料) |
| hp-07-crank.stl | 曲柄臂(D 孔) | 1 | 平躺 |
| hp-08-shaft.stl | 軸(Ø6 帶 D 面) | 1 | 平躺,D 面朝下 |
| hp-09-handle-pin.stl | 手把銷 | 1 | 帽朝下站著 |

## B. 板件直印版(flat/,跟雷切檔同幾何)

木板版的 20 片直接變 STL(疊層件印全厚,合併成 16 件),組裝照[木板版組裝說明](../heart-assembly.html),
一樣要上膠(PLA 用瞬間膠,白膠黏不住)。想跟雷切版完全同款就選這個。檔案在 [`flat/`](flat/)。

## 列印參數(兩版通用)

- PLA、層高 0.2mm、3 層壁、15% 填充,全部免支撐。
- **先印公差測試**:只印一件間隔套(A 版)或軸環(B 版),拿 Ø6 圓棒或印出來的軸試插,
  要「能轉不晃」。太緊就開 XY 孔補償 +0.1~0.2mm 重印,調好再印其餘。FDM 孔會縮,這步不能跳。
- 滑動面(推桿×導套、推桿×凸輪頂面)設計留單邊 0.3mm;印出來有層紋就砂紙輕磨。

> 誠實聲明:兩版都通過模擬三層驗證(逐項幾何檢查/36 角度干涉掃描/STL 逐殼水密+尺寸核對),
> 但**都還沒實際印過**。骷髏頭與心跳凸輪的木板版當初也是同樣狀態,後來切出來真的會動。印了歡迎回報。

## 重新產生

```
python3 -m http.server 8099          # 開著
node export-heart-print-stl.js       # A 版:從 heart-print.html 的幾何出 hp-*.stl
node export-heart-stl.js             # B 版:從 heart.html 的幾何出 flat/heart-*.stl
node heart-print-collide.js          # A 版干涉掃描(改幾何後必跑)
```

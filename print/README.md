# 心跳凸輪 · 3D 列印版

跟雷切版同一份幾何直接產生的 STL(mm)。11 種零件、共印 16 件,全部平躺列印、免支撐。
比木板版少 4 件:疊層件直接印全厚(凸輪 9mm 一件、推桿 6mm 一件、曲柄臂 6mm 一件),免疊層黏合。

> 誠實聲明:這批 STL 通過水密檢查、尺寸與 BOM 逐件核對,但**還沒實際印過**。
> 幾何跟通過三層驗證的模擬同源;印了歡迎回報。

## 每件要印幾份

看 `MANIFEST.txt`(側板、裙板、導片、軸環各 2 件,其餘 1 件)。

## 列印參數建議

- 材料:PLA 就夠;心可以換紅色料。
- 層高 0.2mm、3 層壁、15% 填充;全件平躺,大面朝下。
- **先印公差測試**:印一件軸環,拿 Ø6 圓棒試插。轉不進去就在切片軟體開 XY 孔補償(+0.1~+0.2mm)重印,調到「能轉不晃」再印其餘零件。FDM 孔會縮,這步不能跳過。
- 滑動面(推桿×導套、推桿×凸輪頂面)設計已留單邊 0.3mm;印出來若緊,砂紙磨兩下就好。

## 跟木板版組裝的差異

- 組裝順序照 [組裝說明](../heart-assembly.html) 走,疊層那一步(第 1 步)整步跳過。
- 黏合:PLA 用瞬間膠或塑膠用 AB 膠;白膠黏不住 PLA。
- 軸照舊用 Ø6 圓棒或竹筷。想全列印也可以印 Ø5.8 圓棒試,但長桿平躺印會有接縫稜線,要磨;竹筷比較省事。
- 導套「包紙墊隙」那招照用:紙的厚度就是要留的間隙,跟材料無關。

## 重新產生

```
python3 -m http.server 8099   # 開著
node export-heart-stl.js      # 從 heart.html 的幾何重出全部 STL
```

改了 heart.html 的幾何之後要重跑,並重跑水密/尺寸驗證。

# 骷髏頭凸輪玩具

一根手搖軸、四片凸輪、四個動作(下顎開合、點頭、眼球、轉頭)的木製凸輪機構玩具。

起因是一份 **AI 產生的 1:1 裁切樣板 PDF**。圖面乍看很完整 —— 尺寸線、鑽孔中心、
組裝順序、相位圖全都有,但把向量座標解出來重算之後發現**做不出來**:七個致命問題,
其中「轉頭」那一路即使零件全部完美裁切,自由度也是 0。

這個 repo 是重新推導、逐項驗證過的版本,含 3D 模擬、驗證腳本,以及可以直接下雷切的 1:1 檔案。

**網站:** https://yazelin.github.io/skull-cam-toy/

---

## 拿去做

| | |
|---|---|
| [`cut/cut-all-A4.pdf`](cut/cut-all-A4.pdf) | 1:1 切割檔,A4 五頁,共 47 片 |
| [`cut/cut-*.dxf`](cut/) | 同上的 DXF(雷射軟體通吃,單位 mm) |
| [`cut/cut-*.svg`](cut/) | 同上的 SVG(黑線=切割、藍字=刻字) |
| [`ASSEMBLY.md`](ASSEMBLY.md) | 組裝說明書,十步,每步附「怎麼驗」 |
| [`FINDINGS.md`](FINDINGS.md) | 驗證報告:原始圖面哪裡壞、修正版怎麼驗的 |

材料:3mm 合板 + **只剩兩支圓棒**(Ø6 凸輪軸、Ø4 轉盤撥銷)+ 8×6 方棒(頸脊)+ **兩條橡皮筋**(非加不可,理由見報告)。
導柱、滑銷、軸環全部改成板材卡榫。

每張切割檔底部都有 50mm 校正尺。切之前先量它。

## 程式與工具

| 檔案 | 做什麼 |
|---|---|
| `mech.js` | 運動學核心、15 項幾何檢查、約束盤點表(`DOF`) |
| `profiles.js` | 從樣板 PDF 的貝茲曲線解出來的真實輪廓(頭骨、下顎、兩片凸輪) |
| `sim.html` | three.js 場景。每片木板都登記自己的「2D 外形 + 孔 + 厚度」,供掃描與出圖用 |
| `collide.js` | 干涉掃描:板內佈 1mm 網格取樣點,曲柄轉一圈取 72 個角度,兩兩互測 |
| `bom.js` | 從模型撈零件表 |
| `export-cut.js` | 從模型產生 SVG + DXF 切割檔 |
| `build-site.js` | Markdown → 網站頁面 |

全部需要本機 HTTP:

```bash
python3 -m http.server 8099        # 然後開 http://127.0.0.1:8099/
node collide.js                     # 干涉掃描
node bom.js                         # 零件表
node export-cut.js                  # 重出切割檔
node build-site.js                  # 重出網站頁面
```

**切割檔是從 3D 模型直接撈出來的,不是另外畫的** —— 模型改了重跑一次就同步,不會有「圖跟模型對不起來」的問題。

## 目前的驗證狀態

```
零件自檢                 每個孔都完全落在輪廓內
肉厚自檢                 孔↔孔、孔↔輪廓都 ≥ 2mm
單件自檢                 沒有「同一零件被拆成多片」
15 項幾何檢查            全過
41 片木板 / 136,125 點    轉一圈 72 個角度   零干涉
四組凸輪接觸間隙          0.00 mm
轉頭叉口                  上緣 0.20 / 下緣 0.20 mm,叉底剩 3.0 mm
約束盤點                  只剩兩處力封閉(下顎、眼球推桿)→ 用橡皮筋
```

還沒做:實際切過。榫孔留單邊 0.1mm,雷射有割縫可能偏鬆,建議先切一組榫試配。
